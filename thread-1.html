PROTOTYPE CONCEPT

Thread 1.0

Turn a long message thread into a reviewable account of decisions, actions, and open questions.

Input and output

Review a selected thread or time window. Extract decisions, owners, deadlines, and open questions. Where available, retain a reference back to the message that supports each item.

Keep ambiguity visible

Mark missing owners, conflicting dates, and tentative decisions. A person can correct the summary before sharing it or turning an item into a task.

Illustrative case

A planning thread contains three proposed delivery dates. The summary shows which option was approved, identifies the owner, and leaves a due date open if the messages never confirmed one.
